*STREAMFLARE*

Current features:
* Search by button click returns a list of movies somewhat relevant to search term
* Links to different streaming sites take you to the movie itself
* Displays movie information and a short trailer in a YouTube embed video

Ways to improve current features:
* Search
    * Make search type to search
    * Expand list results displayed to all
    * Add skeleton loader while waiting for response
    * Add filters to list
    * Add sorting to list
    * Add pagination to list
* Movie information
    * Take it from a separate page to a modal when clicking on a button on movie tile
    * Movie tile needs to contain buttons for each streaming service link applicable (i.e. a Netflix logo button) and a button for more info and trailer

Additional Features

* Connect a database to the front end
* login capabilities with password reset/retrieval
* Login with google/apple/yada yada
* ability to “favorite” movies or shows which will tailor results displayed based on genre and year
* Account list of favorited shows that is editable
* Account management
    * Password reset
    * Avatar/picture edit
    * Account info edit
        * Email / name / birthday
